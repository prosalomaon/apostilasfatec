Definição e Anatomia de uma Potência

Potenciação é a forma abreviada de escrever uma multiplicação de fatores iguais.

aⁿ = a · a · a · … · a  (n fatores)
  • $a$ (Base): O número que se repete.
  • $n$ (Expoente): A quantidade de vezes que a base é multiplicada por si mesma.
  • $a^n$ (Potência): O resultado da operação.

Casos Notáveis Básicos

  • $a^1 = a$ — Qualquer número elevado a $1$ é ele mesmo.
  • $a^0 = 1$ (para $a \neq 0$).
  • $0^0$ é uma indeterminação matemática.

Regras de Sinais (Bases Negativas)

O sinal do resultado depende de a base estar entre parênteses e da paridade do expoente:

Expressão Expoente Análise / Expansão Resultado
(-3)² Par (-3) · (-3) +9
(-3)³ Ímpar (-3) · (-3) · (-3) -27
-3² Par -(3 · 3) — o sinal não está elevado -9
  • Base negativa + Expoente Par → Resultado Positivo.
  • Base negativa + Expoente Ímpar → Resultado Negativo.

Propriedades Operatórias

As propriedades funcionam como ferramentas para simplificar expressões algébricas sem a necessidade de calcular valores astronômicos.

P1. Produto de potências de mesma base

Conserva a base e soma os expoentes.

aᵐ · aⁿ = aᵐ⁺ⁿ

Exemplo: $2^3 \cdot 2^4 = 2^{3+4} = 2^7 = 128$

P2. Divisão de potências de mesma base

Conserva a base e subtrai os expoentes.

aᵐ / aⁿ = aᵐ⁻ⁿ   (a ≠ 0)

Exemplo: $\frac{5^6}{5^2} = 5^{6-2} = 5^4 = 625$

P3. Potência de Potência

Conserva a base e multiplica os expoentes.

(aᵐ)ⁿ = aᵐ · ⁿ

Exemplo: $(3^2)^3 = 3^{2 \cdot 3} = 3^6 = 729$

Atenção ao parêntese: $3^{2^3} = 3^8 = 6561 \neq (3^2)^3$.

P4. Distributiva na Multiplicação

(a · b)ⁿ = aⁿ · bⁿ

Exemplo: $(2 \cdot 5)^3 = 2^3 \cdot 5^3 = 8 \cdot 125 = 1000$

P5. Distributiva na Divisão

(a/b)ⁿ = aⁿ / bⁿ   (b ≠ 0)

Exemplo: $\left(\frac{3}{2}\right)^3 = \frac{3^3}{2^3} = \frac{27}{8}$

Expoente Negativo e Expoente Fracionário

Expoente Negativo (Inversão de Base)

Um expoente negativo indica que a base deve ser invertida e o sinal do expoente trocado para positivo.

a⁻ⁿ = (1/a)ⁿ = 1/aⁿ
(a/b)⁻ⁿ = (b/a)ⁿ
  • Exemplo 1: $2^{-3} = \frac{1}{2^3} = \frac{1}{8}$
  • Exemplo 2: $\left(\frac{2}{3}\right)^{-2} = \left(\frac{3}{2}\right)^2 = \frac{9}{4}$

Expoente Fracionário (Ponte para Radiciação)

O expoente fracionário transforma uma potência em um radical: "o que está por cima (numerador) vai para dentro; o que está por baixo (denominador) vai para fora".

a^(m/n) = ⁿ√(aᵐ)
  • Exemplo 1: $8^{\frac{2}{3}} = \sqrt[3]{8^2} = \sqrt[3]{64} = 4$
  • Exemplo 2: $9^{\frac{1}{2}} = \sqrt[2]{9^1} = \sqrt{9} = 3$

Aplicação em Ciência da Computação: Notação Posicional

A potenciação é a base dos sistemas numéricos (Base 2, Base 8, Base 10, Base 16). O valor de cada dígito em uma posição $k$ é determinado por $a_k \cdot r^k$, onde $r$ é a base (radix) e $k$ é a potência associada à posição.

Exemplo: O valor do número binário $1101_2$ convertido para base 10:

1101₂ = (1 × 2³) + (1 × 2²) + (0 × 2¹) + (1 × 2⁰)
1101₂ = (1 × 8) + (1 × 4) + (0 × 2) + (1 × 1)
1101₂ = 8 + 4 + 0 + 1 = 13₁₀

Resumo das Propriedades

Propriedade Regra Memória Visual
Produto (mesma base) $a^m \cdot a^n = a^{m+n}$ Mesma base → soma expoentes
Divisão (mesma base) $\frac{a^m}{a^n} = a^{m-n}$ Mesma base → subtrai expoentes
Potência de potência $(a^m)^n = a^{m \cdot n}$ Expoente sob expoente → multiplica
Distributiva (multiplicação) $(a \cdot b)^n = a^n \cdot b^n$ Distribui o expoente
Distributiva (divisão) $\left(\frac{a}{b}\right)^n = \frac{a^n}{b^n}$ Distribui o expoente
Expoente negativo $a^{-n} = \frac{1}{a^n}$ Negativo = inverte
Expoente fracionário $a^{\frac{m}{n}} = \sqrt[n]{a^m}$ Numerador = dentro, denominador = fora
