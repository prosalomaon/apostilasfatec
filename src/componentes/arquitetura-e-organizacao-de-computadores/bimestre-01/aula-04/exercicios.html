Exercício 1: Calcular a Saída

Determine o valor lógico da saída para as entradas fornecidas.

Questão 1

Dado: A = 1, B = 0, C = 1. Calcule o valor da saída F.

{% if mostrar_respostas %}
Ver resposta

F = (A · B) + C = (1 · 0) + 1 = 0 + 1 = 1.

{% endif %}

Questão 2

Dado: A = 1, B = 1, C = 0. Calcule o valor da saída F.

{% if mostrar_respostas %}
Ver resposta

F = $\bar{A}$ + (B · C) = 0 + (1 · 0) = 0 + 0 = 0.

{% endif %}

Questão 3

Dado: A = 1, B = 0, C = 1. Calcule o valor da saída F.

{% if mostrar_respostas %}
Ver resposta

F = (A ⊕ B) · C = (1 ⊕ 0) · 1 = 1 · 1 = 1.

{% endif %}

Questão 4

Dado: A = 0, B = 1, C = 0. Calcule o valor da saída F.

{% if mostrar_respostas %}
Ver resposta

F = ($\bar{A}$ · $\bar{B}$) + C = (1 · 0) + 0 = 0 + 0 = 0.

{% endif %}

Exercício 2: Circuito → Expressão

Escreva a expressão booleana que descreve cada circuito.

Questão 1

{% if mostrar_respostas %}
Ver resposta

F = (A · B) + $\bar{C}$.

{% endif %}

Questão 2

{% if mostrar_respostas %}
Ver resposta

F = (A ⊕ B) · C.

{% endif %}

Questão 3

{% if mostrar_respostas %}
Ver resposta

F = ($\bar{A}$ · B) + (A · $\bar{B}$), que é equivalente a A ⊕ B.

{% endif %}

Questão 4

{% if mostrar_respostas %}
Ver resposta

F = $\overline{A \cdot \bar{B}}$. Aplicando DeMorgan: F = $\bar{A}$ + B.

{% endif %}
