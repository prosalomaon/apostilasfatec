Atividade Prática: Sistema de Livraria - Modelagem de Dados

1. Enunciado

Nesta atividade, você dará os primeiros passos na Orientação a Objetos aplicando os conceitos de Abstração e Classe. O objetivo é modelar a entidade "Livro" para um sistema de livraria técnica, definindo suas características fundamentais (atributos) e criando instâncias reais na memória.

2. Preparação

  • Localização: Crie os arquivos dentro da sua pasta de projetos Java (ex: src/aula11/).
  • Arquivos Necessários:
    • Livro.java: A classe que servirá como molde.
    • TestaLivro.java: A classe que contém o método main para executar o teste.

3. Passo a Passo

Passo 1: Definindo o Molde (Livro.java)

Crie a classe Livro com os seguintes atributos que representam o estado do objeto:

  • nome (tipo String)
  • descricao (tipo String)
  • valor (tipo double)
  • isbn (tipo String)
public class Livro {
    String nome;
    String descricao;
    double valor;
    String isbn;
}

Passo 2: Criando Objetos (TestaLivro.java)

Agora, crie uma classe de teste. Dentro do método main, você deve:

  1. Instanciar um objeto chamado meuLivro.
  2. Atribuir valores aos seus atributos.
  3. Instanciar um segundo objeto chamado outroLivro com valores diferentes.
  4. Exibir os dados no console.
public class TestaLivro {
    public static void main(String[] args) {
        // 1. Instanciação
        Livro meuLivro = new Livro();
        
        // 2. Definindo o Estado
        meuLivro.nome = "Java e Orientação a Objetos";
        meuLivro.valor = 59.90;
        meuLivro.isbn = "978-85-66250-22-0";

        // 3. Criando outro objeto independente
        Livro outroLivro = new Livro();
        outroLivro.nome = "Lógica de Programação";
        outroLivro.valor = 39.90;

        // 4. Exibindo os dados
        System.out.println("Livro 1: " + meuLivro.nome + " - R$ " + meuLivro.valor);
        System.out.println("Livro 2: " + outroLivro.nome + " - R$ " + outroLivro.valor);
    }
}

4. Desafios de Fixação

  • Independência: Altere o valor de meuLivro.valor e verifique se o valor de outroLivro.valor permanece o mesmo. Isso prova que cada objeto tem seu próprio espaço na memória.
  • Valores Default: Crie um terceiro livro, mas não atribua nenhum valor. Tente imprimir o nome e o valor. O que acontece? (Observe os valores padrão do Java: null para objetos e 0.0 para números).
