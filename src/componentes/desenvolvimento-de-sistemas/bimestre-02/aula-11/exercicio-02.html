Desafio de Fixação: Sistema de Concessionária

1. Enunciado

Você foi contratado para desenvolver o módulo inicial de um sistema para a Concessionária Speed. Sua tarefa é criar um molde para representar os veículos do estoque e realizar o cadastro inicial de alguns carros para teste.

2. Requisitos do Sistema

Implemente as classes seguindo as especificações abaixo:

A. Classe Carro

  • Atributos:
    • fabricante (String)
    • modelo (String)
    • ano (int)
    • cor (String)
    • preco (double)

B. Classe de Teste (Estoque)

  • Crie o método main.
  • Instancie três carros diferentes.
  • Atribua valores que façam sentido (ex: Toyota, Corolla, 2023, Branco, 150000.0).
  • Lógica de Negócio Simples: Ao exibir os dados, utilize uma estrutura de decisão (if) para verificar se o carro é "Novo" (ano >= 2023) ou "Seminovo" (ano < 2023).

3. Exemplo de Saída Esperada

--- Estoque Concessionária Speed ---
Veículo: Corolla (Branco)
Ano: 2023 [NOVO]
Preço: R$ 150.000,00
------------------------------------
Veículo: Civic (Preto)
Ano: 2020 [SEMINOVO]
Preço: R$ 110.000,00
------------------------------------

Dica de Ouro

Lembre-se que para comparar números no if, usamos os operadores relacionais (>, <, >=). Para exibir os dados formatados, você pode usar o System.out.println concatenando as Strings com o operador +.
