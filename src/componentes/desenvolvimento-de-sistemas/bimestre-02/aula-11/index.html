Teoria & Conceitos

A Orientação a Objetos (OO) é um paradigma de programação que tenta aproximar o mundo real do mundo virtual. Em vez de focar apenas em funções e lógica sequencial, focamos em objetos que possuem características e comportamentos.

1. Abstração: O Ponto de Partida

A abstração é o processo mental de identificar as características e comportamentos essenciais de um objeto para o contexto de um sistema, ignorando o que é irrelevante. Se você está desenvolvendo um sistema para uma livraria, um "Livro" precisa de um título e preço, mas talvez não precise do peso ou da cor da capa.

Exemplo Prático: Identificando a Abstração

No mundo real, um livro tem inúmeras propriedades. Para o nosso código, abstraímos apenas o necessário:

  • Entidade: Livro.
  • O que ele tem (Atributos): Nome, descrição, valor, ISBN.
  • O que ele faz (Comportamentos): Aplica desconto, exibe detalhes.

2. Classe: O Molde (Blueprint)

Uma classe é uma especificação, um molde ou uma "planta de engenharia" que define o que os objetos daquele tipo terão e como se comportarão. No Java, toda a lógica deve estar contida dentro de uma classe.

Definindo o Molde

Aqui definimos a classe Livro com seus atributos. Note que esses campos são declarados dentro do corpo da classe (entre as chaves { }), mas fora de qualquer método.

public class Livro {
    // Atributos que definem o estado do objeto
    String nome;
    String descricao;
    double valor;
    String isbn;
}

3. Objeto: A Entidade Concreta

Enquanto a classe é apenas o molde, o objeto é a instância real criada a partir desse molde e que ocupa espaço na memória. Se a classe é a receita de um bolo, o objeto é o bolo pronto.

Criando (Instanciando) Objetos

Para criar um objeto, utilizamos a palavra-chave new. Esse processo é chamado de instanciação.

public class CadastroDeLivros {
    public static void main(String[] args) {
        // Criando uma instância (objeto) da classe Livro
        Livro meuLivro = new Livro(); 
        
        // Criando outra instância independente
        Livro outroLivro = new Livro(); 
    }
}

4. Atributos: O Estado do Objeto

Os atributos (ou variáveis de instância) representam o estado do objeto em um determinado momento. Cada objeto tem sua própria cópia desses atributos; portanto, alterar o valor de um atributo em meuLivro não afeta outroLivro.

Manipulando o Estado

Utilizamos o operador . (ponto) para acessar e atribuir valores aos atributos de um objeto específico.

public static void main(String[] args) {
    Livro livroJava = new Livro();
    
    // Atribuindo valores aos atributos (definindo o estado)
    livroJava.nome = "Java e Orientação a Objetos";
    livroJava.valor = 59.90;
    
    // Recuperando e exibindo os valores
    System.out.println("Nome: " + livroJava.nome);
    System.out.println("Preço: R$ " + livroJava.valor);
}

5. Referências e Memória

É crucial entender que, em Java, a variável (como livroJava) não contém o objeto em si, mas sim uma referência (um endereço de memória) que aponta para onde o objeto foi criado.

  • Valores Padrão: Diferente de variáveis locais, os atributos de uma classe são inicializados automaticamente com valores default (como 0 para números, false para booleanos e null para objetos) se você não atribuir um valor inicial.

6. Comparação Rápida: Classe vs. Objeto

Característica Classe (Molde) Objeto (Instância)
O que é? Uma especificação ou planta. Uma entidade física na memória.
Estado Define quais características existem. Possui valores específicos (ex: valor = 59.90).
Quantidade Existe apenas uma definição no código. Podem existir milhares de instâncias no sistema.

Dicas e Lembretes

  • Nomenclatura: Classes sempre começam com letra MAIÚSCULA (PascalCase). Atributos e variáveis começam com letra minúscula (camelCase).
  • Estado Inicial: Lembre-se que atributos não inicializados ganham valores padrão. Cuidado ao usar null em Strings para evitar erros.
  • Encapsulamento: Por enquanto estamos acessando atributos diretamente com o ponto, mas no futuro aprenderemos a protegê-los (visibilidade private).
