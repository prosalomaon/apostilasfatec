Atividade Prática: Arquitetura do Catálogo "JavaFlix"

1. Enunciado

Você foi contratado para refatorar o sistema de catálogo de uma nova plataforma de streaming. O desenvolvedor anterior criou classes separadas para Filme e Serie, mas copiou e colou muito código, pois ambos possuem título, ano de lançamento e um método para exibir a ficha técnica.

Sua missão é aplicar o conceito de Herança para criar uma superclasse chamada Midia, eliminando a duplicidade de código e organizando as subclasses Filme e Serie usando a palavra-chave extends.

2. Preparação

  • Nome do Arquivo: JavaFlixApp.java
  • Conceitos Focados: Reutilização com extends, uso do construtor com super() e sobrescrita de métodos com @Override.

3. Código Base

Copie o código abaixo para iniciar sua atividade. A estrutura principal e a classe mãe já estão prontas, assim como o método main. Seu foco deve ser exclusivamente construir as classes filhas conectando-as ao pai.

// SUPERCLASSE (Classe Pai)
class Midia {
    protected String titulo;
    protected int anoLancamento;

    // Construtor da classe pai
    public Midia(String titulo, int anoLancamento) {
        this.titulo = titulo;
        this.anoLancamento = anoLancamento;
    }

    public void exibirFicha() {
        System.out.println("Título: " + titulo);
        System.out.println("Ano de Lançamento: " + anoLancamento);
    }
}

// ========================================================
// TODO: VOCÊ DEVE IMPLEMENTAR AS SUBCLASSES AQUI (VEJA O DESAFIO)
// ========================================================


// CLASSE PRINCIPAL (Não mexer aqui, serve para testar seu código)
public class JavaFlixApp {
    public static void main(String[] args) {
        System.out.println("--- Carregando Catálogo JavaFlix ---");

        // Instanciando um Filme (Título, Ano, Duração)
        Filme filme = new Filme("Inception", 2010, 148);
        
        // Instanciando uma Série (Título, Ano, Temporadas)
        Serie serie = new Serie("Stranger Things", 2016, 4);

        // Testando os métodos herdados e sobrescritos
        System.out.println("\n[Ficha do Filme]");
        filme.exibirFicha();

        System.out.println("\n[Ficha da Série]");
        serie.exibirFicha();
    }
}

4. O Desafio

Sua tarefa é escrever o código das subclasses Filme e Serie logo abaixo da classe Midia, seguindo os requisitos técnicos abaixo:

A. Implementar a classe Filme

  • Deve herdar de Midia usando a palavra-chave extends.
  • Deve possuir o atributo específico: private int duracaoEmMinutos;.
  • Deve conter um construtor que receba titulo, anoLancamento e duracaoEmMinutos. Use o super(titulo, anoLancamento) para repassar os dados para o pai.
  • Deve sobrescrever (@Override) o método exibirFicha(). Dentro dele, chame super.exibirFicha() para reaproveitar a impressão do pai e adicione a linha para exibir a duração.

B. Implementar a classe Serie

  • Deve herdar de Midia usando a palavra-chave extends.
  • Deve possuir o atributo específico: private int totalTemporadas;.
  • Deve conter um construtor que receba titulo, anoLancamento e totalTemporadas. Use o super(...) corretamente.
  • Deve sobrescrever (@Override) o método exibirFicha(). Use super.exibirFicha() e adicione a linha para exibir o total de temporadas.

Orientação Finais

  • O erro do Construtor: Se você tentar criar a classe filha e não chamar o super(...) no construtor, o Java vai dar um erro de compilação dizendo que não encontrou um construtor padrão na classe pai. O super deve ser sempre a primeira linha do construtor do filho.
  • Visualização do Polimorfismo: Note que no método main, chamamos .exibirFicha() tanto para o filme quanto para a série. Graças à herança e à sobrescrita, cada objeto responde exibindo suas informações exclusivas, além das informações comuns guardadas no pai.
