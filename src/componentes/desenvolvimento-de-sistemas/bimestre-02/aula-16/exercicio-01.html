1. Enunciado

O departamento de RH da empresa Hero Corp precisa de um novo motor de cálculo de folha de pagamento. A empresa possui diferentes categorias de colaboradores, cada uma com sua própria regra de remuneração. O objetivo é criar um sistema que consiga processar uma lista de diversos funcionários e calcular o total de vencimentos de forma polimórfica, sem que o sistema principal precise conhecer as regras específicas de cada cargo.

2. Preparação

  • Arquivos Necessários:
    • Funcionario.java (Superclasse abstrata).
    • Assalariado.java (Subclasse concreta).
    • Comissionado.java (Subclasse concreta).
    • FolhaPagamento.java (Classe com o método main).
  • Ferramentas: JDK 17+ e IDE (Eclipse, IntelliJ ou VS Code).

3. Código Base (Código Inicial)

Este é o molde geral que define o contrato de todos os funcionários da empresa.

Arquivo: Funcionario.java

// Superclasse abstrata: não pode ser instanciada diretamente
public abstract class Funcionario {
    private String nome;
    private String cpf;

    public Funcionario(String nome, String cpf) {
        this.nome = nome;
        this.cpf = cpf;
    }

    public String getNome() { return nome; }

    // Método abstrato: força as subclasses a implementarem sua própria lógica
    public abstract double vencimentos();

    @Override // Sobrescrevendo toString da classe Object
    public String toString() {
        return String.format("Nome: %s | CPF: %s", nome, cpf);
    }
}

4. O Desafio (Atividade em questão)

Você deve completar o sistema seguindo estes requisitos técnicos baseados no conceito de vínculo dinâmico:

Passo 1: Implementar as Subclasses

  • Assalariado: Deve ter um atributo salarioMensal. O método vencimentos() deve apenas retornar esse valor.
  • Comissionado: Deve ter os atributos totalVendas e taxaComissao. O método vencimentos() deve retornar a multiplicação desses dois valores.

Passo 2: Aplicar o Polimorfismo no Main

No arquivo FolhaPagamento.java, você deve:

  1. Criar um array (ou ArrayList) do tipo geral Funcionario[].
  2. Instanciar objetos de Assalariado e Comissionado e guardá-los nesse array.
  3. Utilizar um laço for (ou for-each) para percorrer o array.
  4. Dentro do laço, chamar o método vencimentos() de cada objeto. Observe que, embora a referência seja Funcionario, o Java executará a regra correta de cada cargo em tempo de execução.

Passo 3: Desafio "Hero" (Opcional)

Utilize o operador instanceof para identificar se um funcionário é Comissionado. Se for, aplique um bônus extra de R$ 200,00 nos vencimentos dele apenas durante o processamento da folha.

5. Orientações Finais

  • Anotação @Override: Não esqueça de usá-la em todos os métodos sobrescritos. Isso garante que você não errou a assinatura do método da superclasse.
  • Programar para o Geral: Repare que o seu loop no main não precisa saber se o funcionário é assalariado ou comissionado para calcular o pagamento. Ele apenas diz: "Funcionário, calcule seus vencimentos".
  • Extensibilidade: Pense que, se amanhã a empresa criar o cargo "Estagiário", basta criar a classe Estagiario extends Funcionario e o seu código de folha de pagamento continuará funcionando sem alterações.
  • Segurança: Lembre-se que você não pode dar new Funcionario(), pois a classe é abstrata para evitar que existam funcionários "genéricos" sem regras de pagamento.
