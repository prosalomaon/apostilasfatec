1. O que é a CLI do Cisco IOS?

A CLI (Command-Line Interface) é a forma de interagir com o sistema operacional dos equipamentos Cisco (o IOS — Internetwork Operating System) digitando comandos em texto. Toda a configuração de switches e roteadores — VLANs, portas, trunking, endereçamento IP — é feita por meio dela.

No Cisco Packet Tracer, a CLI é acessada da seguinte forma:

  1. Clique sobre o equipamento (switch ou roteador).
  2. Na janela que abre, clique na aba CLI.
  3. Ao ligar o equipamento (simulado pelo botão de energia), o prompt Would you like to enter the initial configuration dialog? [yes/no]: aparece. Digite no e pressione Enter.
  4. Será apresentado o prompt de linha de comando, pronto para receber os comandos.
Would you like to enter the initial configuration dialog? [yes/no]: no

Press RETURN to get started!

Switch>

Leitura do prompt

O prompt indica em qual posição da hierarquia você está. Toda vez que ele muda, significa que você entrou (ou saiu) de um modo de configuração. Aprender a ler o prompt é o primeiro passo para não se perder na CLI.

2. A Hierarquia de Modos de Operação

A CLI funciona em camadas. Cada camada é chamada de modo de operação e dá acesso a um conjunto específico de comandos. O equipamento só executa o comando se ele existir no modo em que você está.

A. Modo Usuário (>)

É o modo inicial, de acesso restrito e apenas para visualização básica.

B. Modo Privilegiado (#)

Dá acesso a todos os comandos de visualização (show), diagnóstico e gerenciamento. Para entrar, use o comando enable:

Switch> enable
Switch#

C. Modo de Configuração Global ((config)#)

Dá acesso aos comandos que alteram a configuração do equipamento como um todo. Para entrar, no modo privilegiado, digite:

Switch# configure terminal
Switch(config)#

D. Modos de Configuração Específicos — os "Blocos" ((config-vlan)#, (config-if)#, ...)

A partir da configuração global, alguns comandos abrem um novo modo específico. Esses são os famosos blocos de comando:

  • vlan 10 → entra no bloco da VLAN 10: prompt (config-vlan)#. Todos os comandos digitados a seguir se aplicam àquela VLAN.
  • interface FastEthernet 0/1 → entra no bloco da porta Fa0/1: prompt (config-if)#. Todos os comandos digitados a seguir se aplicam àquela porta.
  • line console 0 → entra no bloco da porta de console: prompt (config-line)#.

Enquanto você estiver dentro de um bloco, os comandos são interpretados dentro daquele contexto — e não no contexto global. Por isso, depois de configurar uma VLAN ou uma porta, é preciso usar exit para voltar e poder digitar outros comandos.

A regra de ouro dos blocos

Dentro de um bloco, os comandos valem apenas para aquele contexto. Ao criar a VLAN 10 (vlan 10), o comando name Vendas seguinte será aplicado à VLAN 10. Para criar outra VLAN (ou configurar portas), você precisa digitar exit para voltar ao modo global e então iniciar o novo bloco.

3. Navegando com exit, end e Ctrl+Z

Existem três formas de sair de um modo:

Comando / Tecla Efeito
exit Sobe um nível na hierarquia (volta ao modo anterior). É o mais usado no dia a dia.
end Volta direto ao modo privilegiado (#), de qualquer profundidade.
Ctrl+Z Atalho que equivale ao end: salta direto ao modo privilegiado.

Exemplo prático — o fluxo das demonstrações do Encontro 04, observando o prompt mudar a cada bloco:

Switch> enable                          ! entra no modo privilegiado
Switch# configure terminal              ! entra no modo global
Switch(config)# vlan 10                 ! abre o BLOCO da VLAN 10
Switch(config-vlan)# name Vendas        ! este comando vale para a VLAN 10
Switch(config-vlan)# exit               ! volta para o modo global
Switch(config)# vlan 20                 ! abre o BLOCO da VLAN 20
Switch(config-vlan)# name Engenharia
Switch(config-vlan)# exit               ! volta para o modo global
Switch(config)# interface FastEthernet 0/1   ! abre o BLOCO da porta Fa0/1
Switch(config-if)# switchport mode access    ! vale para Fa0/1
Switch(config-if)# switchport access vlan 10 ! vale para Fa0/1
Switch(config-if)# exit                 ! volta para o modo global
Switch(config)# end                     ! pula direto para o modo privilegiado
Switch# show vlan brief                 ! verifica o resultado

Se você esquecesse do exit depois do bloco da VLAN 10 e digitasse vlan 20, o prompt (config-vlan)# não permitiria esse comando — porque vlan é um comando do modo global, não do bloco da VLAN.

4. Atalhos e Truques de Produtividade

A. Os atalhos essenciais do IOS

Atalho Função
TabCompleta automaticamente um comando parcialmente digitado.
?Mostra a ajuda contextual: todos os comandos (ou opções) disponíveis naquele ponto da linha.
Seta ↑ / ↓Navega pelo histórico dos comandos já digitados.
Ctrl+AMove o cursor para o início da linha.
Ctrl+EMove o cursor para o final da linha.
Ctrl+CCancela/descarta a linha atual e retorna ao prompt (ou aborta o comando em execução).
Ctrl+ZEquivale ao end: volta direto ao modo privilegiado.
Ctrl+WApaga a palavra anterior ao cursor.
Ctrl+UApaga toda a linha atual.
Ctrl+H / BackspaceApaga o caractere anterior ao cursor.
Ctrl+Shift+6Interrompe processos longos (ex.: perquisas de DNS, pings infinitos).

B. Abreviações de comandos (abbreviation)

O IOS aceita abreviações únicas — você só precisa digitar caracteres suficientes para identificar o comando sem ambiguidade:

Comando completo Abreviação comum
enableen
configure terminalconf t
interface FastEthernet 0/1int fa0/1
show vlan briefsh vlan br
show interfaces trunksh int tr
show running-configsh run

C. O prefixo no

Usar no antes de um comando remove/desfaz a configuração:

  • no vlan 10 → remove a VLAN 10.
  • no switchport access vlan 10 → remove o vínculo da porta com a VLAN 10.
  • no shutdown → liga a interface (na Cisco, shutdown desliga; no shutdown ativa).

D. Executando comandos show dentro do modo de configuração

Se quiser visualizar a configuração sem sair do bloco em que está, use o prefixo do:

Switch(config-vlan)# do show vlan brief
Switch(config-if)# do show interfaces status

5. Lista Completa de Comandos

Este guia reúne, em ordem de uso, todos os comandos de VLANs, portas, trunks e SVIs vistos nas demonstrações — com as abreviações aceitas pelo IOS ao lado de cada comando.

1. Administração e Criação de VLANs

Comando Completo Abreviação Definição / Descrição
vlan <ID> vl <ID> Entra no modo de configuração da VLAN (cria a VLAN se ela não existir).
name <TEXTO> name <TEXTO> Atribui um nome identificador à VLAN (facilita a gestão).
vlan <ID1,ID2,ID3-ID4> vl <ID1,ID2,ID3-ID4> Cria múltiplas VLANs individuais ou em intervalo de uma só vez.
no vlan <ID> no vl <ID> Exclui uma VLAN do banco de dados do switch.

2. Atribuição de Portas (Modo Access)

Comando Completo Abreviação Definição / Descrição
interface <TIPO/PORTA> int <TIPO/PORTA> Entra no modo de configuração de uma interface específica (ex: fa0/1).
interface range <TIPO/INICIO - FIM> int range <TIPO/INICIO - FIM> Seleciona um grupo/intervalo de portas para configurar juntas.
switchport mode access sw mo acc Define a porta explicitamente como porta de acesso (para conectar hosts).
switchport access vlan <ID> sw acc vl <ID> Associa a porta (ou intervalo de portas) a uma VLAN específica.
no switchport access vlan no sw acc vl Remove a porta da VLAN atribuída e a devolve para a VLAN 1 padrão.

3. Configuração de Links Tronco (Trunk)

Comando Completo Abreviação Definição / Descrição
switchport mode trunk sw mo tr Força a interface a operar como tronco (transporta múltiplas VLANs).
switchport trunk encapsulation dot1q sw tr enc dot Define o padrão de encapsulamento 802.1Q (obrigatório antes do sw mo tr em switches L3).
switchport trunk allowed vlan <LISTA> sw tr all vl <LISTA> Define estritamente quais VLANs têm permissão para atravessar o tronco.
switchport trunk allowed vlan add <ID> sw tr all vl add <ID> Adiciona uma VLAN à lista de permissões sem sobrescrever as existentes.
switchport trunk allowed vlan remove <ID> sw tr all vl rem <ID> Remove uma VLAN específica da lista de permissões do tronco.
switchport trunk allowed vlan all sw tr all vl all Restaura a permissão para que todas as VLANs trafeguem pelo tronco.
switchport trunk native vlan <ID> sw tr nat vl <ID> Altera a VLAN Nativa do tronco (tráfego sem etiqueta 802.1Q).
switchport nonegotiate sw noneg Desativa o protocolo DTP (evita que a porta negocie tronco automaticamente por segurança).

4. Interface Virtual de Gerenciamento (SVI)

Comando Completo Abreviação Definição / Descrição
interface vlan <ID> int vl <ID> Cria/acessa a SVI (interface lógica L3) associada a uma VLAN.
ip address <IP> <MASCARA> ip add <IP> <MASCARA> Atribui um endereço IP e máscara de rede à SVI do switch.
no shutdown no shut Ativa a interface lógica (liga a SVI).
ip default-gateway <IP> ip def <IP> Configura o IP do roteador padrão no switch (necessário em switches L2).

5. Diagnóstico e Verificação (Privileged EXEC #)

Comando Completo Abreviação Definição / Descrição
show vlan brief sh vl br Exibe a tabela resumida com todas as VLANs, status e portas associadas.
show interfaces trunk sh int tr Exibe as portas tronco ativas, modo de encapsulamento e VLANs permitidas.
show interfaces <PORTA> switchport sh int <PORTA> sw Mostra os detalhes de Camada 2 negociados na porta (Modo, VLAN Nativa, DTP).
show running-config interface <PORTA> sh run int <PORTA> Exibe exatamente as linhas de comando configuradas naquela interface.
show ip interface brief sh ip int br Lista o status operacional e os IPs atribuídos às interfaces (incluindo SVIs).

6. Salvamento e Reset de Memória

Comando Completo Abreviação Definição / Descrição
copy running-config startup-config wr Salva as configurações ativas da RAM na NVRAM.
delete flash:vlan.dat del flash:vlan.dat Apaga o arquivo do banco de dados de VLANs da memória flash.
erase startup-config erase start Limpa as configurações salvas no switch (restaura padrão de fábrica após o reload).
reload reload Reinicia o equipamento físico/simulado.

6. Erros Comuns na CLI e Como Identificá-los

Sintoma Mensagem Provável causa
Comando recusado % Invalid input detected O comando não existe naquele modo (ex.: digitou comando de bloco fora do bloco) ou tem erro de digitação.
Autocompletar falhou % Ambiguous command A abreviação usada é ambígua — digite mais caracteres.
Empacou num bloco O prompt continua (config-if)# Esqueceu do exit (ou end/Ctrl+Z).
Configuração não aplicada show running-config sem a mudança Foi configurada a porta errada, ou a VLAN ainda não existia.
Símbolos % antes do prompt % Unknown command etc. Comando mal digitado naquele modo — verifique o prompt atual.

Três boas práticas para não se perder

  • Sempre olhe o prompt: ele diz em qual bloco você está.
  • Use Tab e ? o tempo todo: evita erros de digitação e ensina os comandos disponíveis.
  • Confirme com show: depois de cada bloco, use show vlan brief, show running-config ou show interfaces status para validar o que foi aplicado.
